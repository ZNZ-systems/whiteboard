Whiteboard for Linear

Keep Linear in view while reading a real, saved Whiteboard review. This extension requests data only from your local server. Selected review content is rendered in the Linear page, whose scripts can inspect it.

1. Connect your local Whiteboard

Install the Whiteboard CLI, then start its authenticated loopback server:

whiteboard server start

Import <stateDir>/review-server/server.json from the state directory used by the server. Start the server again and reimport if the connection expires.

Checking connection…

The credential stays in trusted extension storage on this browser. It is not synced, displayed, or exposed to Linear or the page’s content script. Importing a new connection clears existing bindings.

2. Choose an issue and saved review

Select one review to explicitly allow it on this issue.

The page can read only its bound review and saved version. Refresh in the panel advances to the latest saved version of that same review; selecting a different review requires these settings.

Issue bindings

    Return to the Linear issue and select Open Whiteboard. Closing the panel or navigating to another issue removes the current review canvas.
